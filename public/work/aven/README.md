# AVEN, архитектурное бюро

Одностраничный сайт для раздела работ North Studio. Статика без сборки, как
`domstroy` и `dental-clinic`: отдаётся из `public/work/aven/` и переписывается
на адрес `/work/aven` в `next.config.ts`.

```
aven/
├── index.html            разметка, данные проектов в <script type="application/json">
├── css/style.css         токены, темы, адаптив, reduced motion
├── js/main.js            заставка, сцены прокрутки, просмотр проекта
├── js/vendor/            GSAP 3.15 (+ScrollTrigger, SplitText), Lenis 1.3.26
└── images/               8 фото: <name>.jpg 1672px и <name>-960.jpg для телефонов
```

Исходные PNG (около 20 МБ) в репозиторий не попадают и на сайт не выкладываются.

## Разделы

| Раздел | Фото | Что происходит |
|---|---|---|
| Заставка | — | Линия чертежа растёт, пока грузятся шрифты и главное фото, затем расходится на две и открывает дом |
| Герой | `hero` | Фото уменьшается от 1.22, строки заголовка выезжают из-под маски, при прокрутке лёгкий параллакс |
| О бюро | `about` | Фото раскрывается слева направо, цифры по очереди, соседние цифры приглушаются на наведении |
| Проекты | `project-*` | На широком экране секция встаёт, лента едет вбок; слово «Проекты» отстаёт, внутри кадров свой параллакс |
| Просмотр проекта | `project-*` | `<dialog>` с описанием и фактами; соседние проекты сменяются мягким наплывом, стрелки и Esc работают |
| Услуги | `services` | Активная строка меняет кадрирование фото: на наведении или сама по ходу прокрутки |
| Процесс | `process` | Секция встаёт, поверх неё рисуется чертёж: участок, объём, детали; на четвёртом этапе проступает фото стройки |
| Вопросы | — | Аккордеон на `<details>`, высота анимируется |
| Контакты | `cta` | Фото проявляется из темноты, кнопка ведёт в Telegram |

Тема страницы (кремовая или угольная) меняется плавно, когда в центр экрана
приходит полоса другого грунта: `data-theme` на `<html>` и переход на
зарегистрированных через `@property` цветах. Шапка прячется при прокрутке
вниз и возвращается при прокрутке вверх.

## Датум

Шкала внизу экрана: индикатор прокрутки и подпись текущего раздела,
нарисованные как масштабная линейка с чертежа. На телефоне видна только на
первом экране, чтобы не ложиться на фотографии.

## Чертёж

SVG в разделе «Процесс» обведён по `images/process.jpg` в его собственных
координатах (`viewBox="0 0 1672 940"`) и масштабируется так же, как фото
(`preserveAspectRatio="xMidYMid slice"` против `object-fit: cover`), поэтому
линии совпадают с плитой, опорами и террасой при любом размере кадра.
Если заменить фото, контуры нужно обвести заново.

## Грабли, на которые уже наступили

- `gsap.from()` берёт конечное значение из вычисленного стиля. Если у элемента
  есть CSS-переход по той же свойству, GSAP ловит его на середине и оставляет
  элемент прозрачным. Поэтому везде `fromTo` с явным концом, а у групп
  с переходами на время появления стоит `.is-revealing`.
- Порядок сборки: закреплённые секции создаются первыми, иначе ScrollTrigger
  посчитает позиции нижних блоков без места, которое занимают закрепления.
- `img { max-width: 100% }` урезает кадры шире 100 %, которые нужны для
  параллакса внутри рамки: у таких картинок `max-width: none`.
- `<button>` не растягивается на ширину колонки даже с `display: block`.

## Без JS и с reduced motion

Без JS заставки нет, всё содержимое видно сразу, фото стройки показано без
чертежа. При `prefers-reduced-motion: reduce` нет заставки, плавной прокрутки,
закреплений и параллакса. Если скрипт не запустился вовсе, через 6 секунд
заставку снимает страховка из `<head>`.
