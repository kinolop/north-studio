# DOMSTROY: лендинг строительной компании

Статическая страница без сборки. Открывается двойным кликом по `index.html`,
но лучше поднять локальный сервер, иначе часть браузеров ругается на пути.

```bash
npx -y serve DOMSTROY -l 5520
```

## Структура

```
DOMSTROY/
  index.html          вся разметка, блоки пронумерованы комментариями 01..12
  css/style.css       стили, оглавление в шапке файла (21 раздел)
  js/main.js          сценарии, тоже с оглавлением (09 разделов)
  images/
    hero.jpg
    projects/         d-198.jpg, d-156.jpg, d-112.jpg
    works/            work-1.jpg .. work-4.jpg
    _source/          исходные PNG от заказчика, на сайте не используются
  README.md
```

Иконки взяты из [Tabler Icons](https://tabler.io/icons) (лицензия MIT) и вшиты
в `index.html` как SVG-спрайт. Новую иконку добавлять туда же новым `<symbol>`.

страница тёмная по замыслу, и такие картинки её только замусорят.

в том же разрешении, вместе 2,6 МБ. При замене фото держите такой же порядок
величин, иначе первый экран будет грузиться заметно дольше.

## Калькулятор

Квиз на первом экране и живой калькулятор в секции 09 считают по одной формуле,
чтобы цифры не расходились. Всё лежит в разделе 01 файла `js/main.js`:

```js
var RATE    = { frame: 37500, timber: 43500, block: 46500 };  // рублей за м²
var FLOOR_K = { "1": 1, "2": 0.96, attic: 0.98 };             // поправка на этажность
```

Дома больше 90 м² считаются с понижающим коэффициентом до 6 процентов: общие
фундамент и кровля дешевеют в пересчёте на метр. Срок строительства считает
`daysOf()`. Меняйте ставки здесь, править разметку не нужно.

Цифры в примере сметы (секция 06) заданы прямо в разметке: значение в
`data-count`, длина полосы в `style="--w:..."`. Проценты считаются от самой
крупной статьи, а не от итога.

## Оформление

Палитра выведена из фотографий объектов: съёмка в синий час, тёмное небо,
тёплый свет в окнах. Акцент приглушённый и работает точками, а не заливками:
кнопки светлые, цветом отмечены только знак рубля, ключевые цифры, активные
состояния и размерные линии. Все токены в разделе 01 файла `css/style.css`.

| Токен        | Значение  | Роль                                  |
|--------------|-----------|---------------------------------------|
| `--ink`      | `#0C0D0E` | фон страницы                          |
| `--ink-2`    | `#121314` | подложка секций через одну            |
| `--surface`  | `#17191A` | карточки и панели                     |
| `--line`     | `#26292B` | хайрлайны                             |
| `--bone`     | `#ECEAE6` | основной текст и главная кнопка       |
| `--accent`   | `#B8874E` | единственный акцент, приглушённая бронза |

Если менять фирменный цвет, правьте `--accent` и `--accent-2`, остальное
подтянется. Не делайте акцент насыщеннее: на крупных плитах он сразу
удешевляет страницу.

Шрифты с Google Fonts: `Playfair Display` в заголовках, `Manrope` в тексте,
`IBM Plex Mono` в технических подписях и цифрах. Все три с кириллицей.
Антиква в заголовках задаёт издательский тон, гротеск оставлен там, где
текст надо читать быстро.

Скругление одно на весь проект: `--r: 3px`. Мягкие крупные радиусы из
макета убраны намеренно, они читаются несерьёзно.

Поверх страницы лежит слой `.grain` с плёночным зерном в 4 процента: он
убирает плоскость сплошных заливок.

## Анимации

Сквозная идея «замер и сборка». Строки заголовков поднимаются из-под маски,
размерные линии с чертежа вычерчиваются слева направо, числа набегают,
направляющая между этапами рисуется по мере прокрутки, у карточек проектов при
наведении зажигается свет в окнах.

Технически:

* появление ведёт `IntersectionObserver` по атрибуту `data-reveal`
  (`up`, `rise`, `mask`, `draw`), задержка задаётся `data-reveal-delay`;
* у варианта `mask` наблюдение висит на обёртке, а не на самом тексте: текст
  сдвинут за её пределы и для наблюдателя имеет нулевую площадь;
* параллакс фотографий и отрисовка линии этапов сделаны на CSS
  `animation-timeline: view()` там, где браузер это умеет;
* обработчиков `window.onscroll` нет ни одного;
* при `prefers-reduced-motion: reduce` всё выключается, страница остаётся
  полностью читаемой;
* если скрипты не загрузятся, класс `js` не появится и блоки появления
  отключатся: текст и суммы будут видны сразу.

## Галерея и отзыв

Секция «Построенные дома» собрана мозаикой на 12 колонок: крупный кадр слева
держит два ряда, два средних справа, панорама 32:9 закрывает всю ширину снизу.
Раньше здесь была лента из четырёх мелких плиток, и вокруг оставалось пустое
чёрное поле. На планшете мозаика становится двухколоночной, на телефоне
одноколоночной.

Следом идёт полоса с отзывом во всю ширину поверх фотографии. Она нужна не
для красоты: это единственное место с социальным доказательством, и она же
разбивает сплошную темноту между галереей и блоком гарантий.

## Карточка проекта

Клик по «Подробнее о проекте» открывает модальное окно с фотографией,
характеристиками, составом работ и планировкой. Данные лежат в массиве
`PROJECTS` в разделе 10 файла `js/main.js`, порядок совпадает с порядком
карточек в секции «Выберите свой дом». Разметка окна собирается в функции
`build()`, поэтому новый проект добавляется одним объектом в массив.

Окно закрывается по Escape, клику по фону и крестику, фокус заперт внутри и
возвращается на кнопку, с которой открыли. Прокрутка страницы блокируется с
компенсацией ширины полосы, чтобы вёрстка не дёргалась.

## Карта в секции «География работ»

Контур Московской области и границы Москвы построены по данным
[OpenStreetMap](https://www.openstreetmap.org/copyright) (лицензия ODbL) через
Nominatim и упрощены алгоритмом Дугласа-Пекера до 340 и 128 точек. Пины стоят
в настоящих координатах районных центров, проекция равнопромежуточная с
поправкой на косинус широты. Атрибуция выведена подписью под картой, убирать
её нельзя.

Районы и объекты заданы в двух местах, порядок должен совпадать:
строки списка в разметке (`.dists`), пины в `#mapPins` и массив `OBJECTS`
в разделе 07 файла `js/main.js`.

## Проверено

Разметка проверена в Chrome на 1440px и в эмуляции 375px: горизонтального
переполнения нет, ширина документа равна ширине окна. Меню на узких экранах
сворачивается в бургер, ленты этапов и работ прокручиваются пальцем и мышью,
пины на схеме доступны с клавиатуры.
