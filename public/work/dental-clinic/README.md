# Dental Clinic — лендинг

Открыть: двойной клик по `index.html` (работает без сервера) или

```bash
python -m http.server 5310 --directory "dental-clinic"
```

## Структура

```
dental-clinic/
├─ index.html          вся разметка, секции подписаны комментариями
├─ css/style.css       стили, разбиты на 21 пронумерованный блок
├─ js/main.js          интерактив
└─ images/             фон hero + пустые папки под ваши фото
```

## Куда вставлять фото

Каждая заглушка на странице подписана нужным путём и размером. Кладёте файл по этому пути
и меняете `<span class="ph">…</span>` на `<img>`:

```html
<!-- было -->
<div class="card__media"><span class="ph">Фото · 720×450<br><i>images/services/therapy.jpg</i></span></div>

<!-- стало -->
<div class="card__media"><img src="images/services/therapy.jpg" alt="Лечение кариеса"></div>
```

Для «до/после» вместо `<span class="ph">` внутри `.ba__pane` ставится `<img>` — раскладка уже готова.

| Секция | Путь | Размер | Штук |
|---|---|---|---|
| Hero (уже стоит) | `images/hero-clinic.png` | 1536×1024 | 1 |
| Услуги | `images/services/therapy · implants · veneers · ortho.jpg` | 720×450 | 4 |
| До / после | `images/cases/case-N-before.jpg`, `case-N-after.jpg` | 640×420 | 8 |
| Врачи | `images/doctors/doc-1…4.jpg` | 600×760 (портрет) | 4 |
| Видео о клинике | `images/misc/clinic-video-cover.jpg` | 900×640 | 1 |
| Карта | `images/misc/map.jpg` или iframe Яндекс.Карт | 900×520 | 1 |

Чтобы фото заполняло блок без искажений, добавьте в CSS:

```css
.card__media img, .doc__media img, .video img, .map img, .ba__pane img{
  width:100%; height:100%; object-fit:cover;
}
```

## Что уже работает

Кнопки нажимаются, но никуда не уводят — вместо перехода отклик на месте:

- меню и логотип — плавная прокрутка к секции с поправкой на шапку;
- «Записаться на приём» (в шапке и в hero) — модальное окно с формой;
- формы — валидация, маска телефона `+7 (___) ___-__-__`, экран «Заявка принята», автосброс;
- «Что входит» и «Об образовании» — раскрытие блока в карточке;
- «Показать остальные позиции прайса» — таблица на 8 строк;
- «До / после» — перетаскивание ползунка мышью, пальцем и стрелками клавиатуры;
- стрелки в кейсах — прокрутка карусели;
- телефон и почта — копирование в буфер и уведомление;
- «Смотреть видео», «Построить маршрут», «Политика конфиденциальности» — уведомление-заглушка.
